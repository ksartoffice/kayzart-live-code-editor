# テンプレートライブラリ 3.5.1

## 目的と画面

3.5.1では、同梱のBusiness Motion日本語版・英語版をグリッドで表示する。
カードの「詳細・プレビュー」でダイアログを開き、詳細、バージョン、
PC／スマホプレビュー、ページタイトル、下書き作成をまとめて操作する。
カードは名前とバッジを同じ行に配置し、説明は最大2行とする。
カードの画像・タイトル・説明・余白も、既存ボタンと同じ詳細表示の操作領域とする。
ポリシーリンクは独立して操作でき、キーボードの詳細表示用フォーカスは1つとする。
Google Fontsへの接続とポリシーはカードで短く告知する。
写真が使用例であること、フォント名と接続の詳しい説明は詳細画面で表示する。
タイトルは画面内で共有し、カード・言語・開始方法を切り替えても保持する。
作成失敗時は対象カードの詳細を再表示し、入力と再試行IDを保持する。

新しいテンプレート、ZIPアップロード、購入リンク、外部カタログ取得、
追加済みテンプレートの保存・更新・削除はこの版に含めない。
一覧を開くだけでは外部通信しない。既存ページへの変更やDB移行もない。

## 同梱テンプレートを追加する

1. パッケージを作る。既存manifestのスキーマ1／2を使い、HTML、CSS、
   サムネイル、PNG画像、必要に応じてModule JSと許可されたフォントを宣言する。
2. `Template_Registry::entries()`の登録定義に、固有IDで1件追加する。
   公開フィルターやフォルダの自動走査は使わない。
3. 翻訳、パッケージ検証、一覧・プレビュー・ページ作成と配布ZIPを確認する。

登録定義の項目:

| 項目 | 内容 |
| --- | --- |
| 配列のキー | manifestと同じテンプレートID。公開後は変更しない |
| `title` / `description` | 英語リテラルを`__()`で翻訳する名前・説明 |
| `directory` | 信頼できるローカルパッケージの絶対パス |
| `baseUrl` | 同じパッケージの公開URL。末尾に`/`を付ける |
| `locales` | 本文言語コードとネイティブ言語名の対応 |
| `source` | 現在は`bundled` |
| `tier` | 現在の同梱品は`free`。販売区分は実体の有無と分ける |
| `sortOrder` | 小さい値から表示する。登録の配列順に依存させない |
| `retired` | `true`は新規作成の一覧から除外する互換用パッケージ |

バージョン、ファイル名、サムネイル、ローカライズされたファイル、JS、
フォントはmanifestが正本。登録定義へ重複して書かない。
新規パッケージでもカード描画、JSイベント、ページ作成処理の変更は不要。
PNG・HTML・CSS・JSの既存制限は維持している。任意の外部HTML素材を
そのまま同梱できるという意味ではない。

`Template_Library::catalog()`はファイルパスを含まない一覧情報を返す。
`get()`は登録先を解決した実体を返し、`preview()`とページ作成が共用する。
サムネイル・画像・プレビューCSPも登録先を参照するため、読み込み処理は
`assets/templates/free/{id}`という配置へ依存しない。
欠損・不正manifestのパッケージは一覧から除外し、他の正常なカードを表示する。

## 後続の外部カタログとZIP取り込み

外部の商品紹介とローカルの実体は、共通のテンプレートIDと言語で照合する。
販売区分（無料／有料）と利用可能状態（実体あり／未追加）を分離する。
`catalog()`の`source`・`tier`・`hasPackage`は、その区別を表す情報であり、
この版でオンライン商品や購入認証を実装するものではない。

後続では公開JSONとサムネイルを配信し、ZIPの内容や有料ソースは公開JSONに
含めない。ZIP取り込み後は同じカードを追加済みとして扱う。
販売終了やカタログ通信障害でも、ローカルのテンプレートと作成済みページは
使い続けられる設計にする。購入履歴と連携しない限り「購入済み」とは表示しない。
外部通信の入口・説明、キャッシュ、対応版判定、ZIP検証は後続の実装範囲とする。

## 検証

PHPテストでは、テスト用の一時ディレクトリに別ID・別配置・追加言語の
パッケージを作り、登録だけで一覧・プレビュー・ページ作成へ接続できることを
確認する。テスト用の登録差し替えはReflectionを使い、公開登録APIは追加しない。
生成したファイルと登録差し替えは`finally`で回収する。
E2Eではカード・ダイアログ・固定ページ作成を確認する。複数列の表示だけを
確認する追加カードはブラウザ内の一時要素とし、配布・DBへ追加しない。

### カードの高さの調整（2026-11-02）

画面確認後、名前と無料バッジを同じ行にし、一覧の説明を2行へ制限した。
写真の注意書きとフォント名・接続の詳しい説明は詳細画面へ集約し、
一覧にはGoogle Fontsへの接続の短い告知とポリシーリンクを残した。
画像の4:3比率と詳細の全文表示は維持する。
幅360pxの実測は英語459px、日本語476px。確認画像は前記の画像フォルダの
`compact-en_US.png`・`compact-ja.png`。

- PHPのテンプレート関連32件・208 assertionsが合格。変更PHPのPHPCS／PHPCompatibilityWPも指摘なし。
- WP 7.1.3で作成・公開と表示のE2E 2件、WP 5.9で表示のE2E 1件が合格。
- 390／768／1024／1440pxでカード高540px以下、横はみ出しなしを確認。
- 新しい接続告知の日本語訳を生成し、配布ZIPを再生成。463エントリ、2,094,447 bytes。
- 更新ZIPを独立サイトへインストールしてPlugin Checkを再実行し、指摘なし。

### Linux CIのパス検証修正（2026-11-02）

GitHub Actionsではプラグインを`WP_PLUGIN_DIR`の外で読み込むため、
WordPressが生成する仮の公開URLにリポジトリの絶対パスが含まれる。
新規の再試行画面テストが、その正当な公開URLをファイルパスの漏出と誤検出し、
PHPUnitマトリクスで失敗した。
既知の公開URL基点を除いてから、実パスとスラッシュ正規化後のパスが
HTMLに残らないことを検証するよう修正した。製品コードと配布ZIPの変更はない。
関連32件はWP 7.1.3／PHP 8.2で209 assertions、
WP 5.9／PHP 7.4で204 assertions・1件スキップ、失敗なし。

### カード全体のクリック対応（2026-11-02）

既存の詳細ボタンの疑似要素をカード全体へ広げ、画像・タイトル・説明・余白の
クリックでも同じ詳細を開く。カード自体にはイベントやフォーカス項目を追加しない。
ポリシーリンクと、ダイアログ未対応ブラウザで表示するフォームは操作領域の上へ置く。
無効なボタンは操作領域を広げない。ホバーとキーボードフォーカス時は枠を強調する。
詳細ボタンのアクセシブルな名前には対象テンプレート名を含める。

- WP 7.1.3の作成・公開／表示E2E 2件、WP 5.9の表示E2E 1件が合格。
- 390px・1440pxで画像・タイトル・余白、Enter／Space、フォーカス復帰、ポリシーの別画面表示、無効時の操作拒否を確認。
- PHP関連32件・209 assertions、型検査、変更PHPのPHPCS／PHPCompatibilityWPが合格。
- 配布ZIPを再生成。463エントリ、2,094,640 bytes。
- 更新ZIPを独立サイトへインストールし、Plugin Checkも指摘なし。
